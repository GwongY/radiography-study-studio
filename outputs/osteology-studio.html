Sources / architecture

Designed for replaceable anatomy assets

Active model: five separate, real BodyParts3D upper-limb GLBs: clavicle, scapula, humerus, radius and ulna. They are loaded locally and mapped into the canonical anatomy database at runtime; the procedural scene is only a last-resort fallback.

Model attribution

BodyParts3D / Anatomography, © The Database Center for Life Science, licensed under CC BY-SA 2.1 JP. Files are distributed through the open anatomy-viewer study project, which documents the per-bone BodyParts3D source and share-alike attribution.

Candidate sources reviewed

  • BodyParts3D upper-limb GLBs — active real per-bone source.
  • NIH 3D Human Skeleton, 3DPX-016838 — accurate CT-derived source, but the exported GLB is a single fused mesh and is not used for bone picking.
  • Three.js GLTFLoader — direct local GLB loading boundary. Only the model adapter needs to change when assets are replaced.

Radiography-ready data

Each record already has landmarks, articulations, radiography importance, difficulty and a future resource slot. Add openly licensed AP, PA, lateral or oblique studies to the data layer when the image source is cleared.

Offline and failure behavior

Anatomy search, records, regions and quiz choices render without the 3D dependency. If the local BodyParts3D assets or Three.js CDN are unavailable, the model area exits with a retryable fallback state instead of leaving an infinite spinner.
